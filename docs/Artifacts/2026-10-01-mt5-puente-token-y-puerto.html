Puente MT5: preparar el token y el puerto

Cómo dejar listo el puente mt5-bridge/bridge.py de Flash Signals: generar un token seguro, configurarlo en el puente y en Configuración, elegir el puerto, correr dos terminales (Conf principal / Conf secundaria) y por qué no hace falta abrir puertos en el firewall.

  • El token es una contraseña compartida: la API la manda en la cabecera X-Bridge-Token y el puente rechaza (401) cualquier petición sin ella.
  • El puerto es donde escucha el puente (por defecto 8765), siempre en 127.0.0.1.
  • El puente habla con MT5 por la librería oficial MetaTrader5, que se conecta al terminal abierto sin red: MT5 no necesita ningún puerto adicional.
¿Es obligatorio el token? No: si el puente arranca sin MT5_BRIDGE_TOKEN acepta peticiones locales sin token. Es recomendable porque impide que cualquier otro programa de tu PC (o una página web maliciosa abierta en el navegador) mande órdenes al puente.

1Generar un token seguro

Usa un valor aleatorio largo (32 bytes). Cualquiera de estas opciones sirve; copia el resultado.

PowerShell (Windows)
$b = New-Object byte[] 32
[Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($b)
-join ($b | ForEach-Object { $_.ToString('x2') })
Python
python -c "import secrets; print(secrets.token_urlsafe(32))"
Reglas del token Máximo 200 caracteres · no lo subas a git ni lo pegues en chats/capturas · usa uno distinto por puente si tienes dos terminales · si se filtra, genera otro y actualízalo en el puente y en la app.

2Configurar el token en el puente

El puente lee el token de la variable de entorno MT5_BRIDGE_TOKEN. Antes, abre MT5, inicia sesión (cuenta demo recomendada) y activa Algo Trading en la barra de herramientas.

Opción A · Solo para esta sesión

PowerShell · carpeta flash-signals-angular
$env:MT5_BRIDGE_TOKEN = 'PEGA_AQUI_TU_TOKEN'
.\run-mt5-bridge.ps1

Opción B · Permanente para tu usuario

PowerShell
[Environment]::SetEnvironmentVariable('MT5_BRIDGE_TOKEN', 'PEGA_AQUI_TU_TOKEN', 'User')
# Cierra y vuelve a abrir PowerShell para que la variable esté disponible
.\run-mt5-bridge.ps1

Si todo va bien, la consola muestra algo como:

Salida esperada
[mt5-bridge] Conectado a MT5: {'login': 12345678, 'server': 'Broker-Demo', 'demo': True, ...}
[mt5-bridge] Escuchando en http://127.0.0.1:8765  (magic=260901, allowReal=False)
Cuentas reales El puente bloquea cuentas REAL salvo que arranques con MT5_ALLOW_REAL=1. Esa variable vive solo en el puente, a propósito: no se puede activar desde el navegador.

3Configurar el token en Flash Signals

  1. Abre Configuración (/configuracion).
  2. En Configuración para operar en MT5 elige el perfil que usarás (Conf principal o Conf secundaria).
  3. En la pestaña Editar … de ese perfil: URL del puente = http://127.0.0.1:8765 y pega el mismo token en Token del puente.
  4. Pulsa Guardar y luego Probar conexión: debe mostrar Conectado, la cuenta DEMO/REAL, balance y Algo Trading activado.
Dónde se guarda En data/mt5-settings.json (ignorado por git). La API nunca devuelve el token a la web: solo verás guardado. Deja el campo vacío para mantenerlo o marca Quitar token para borrarlo.

4Elegir y comprobar el puerto

Por defecto el puente usa 8765. Cámbialo con MT5_BRIDGE_PORT si está ocupado.

¿Está libre el puerto?

PowerShell
# Sin resultado = libre. Con resultado, OwningProcess es el PID que lo usa
Get-NetTCPConnection -LocalPort 8765 -ErrorAction SilentlyContinue |
  Select-Object LocalAddress, LocalPort, State, OwningProcess

# ¿Qué programa es?
Get-Process -Id (Get-NetTCPConnection -LocalPort 8765).OwningProcess

Usar otro puerto

PowerShell
$env:MT5_BRIDGE_PORT = '8770'
.\run-mt5-bridge.ps1
# Y en Configuración: URL del puente = http://127.0.0.1:8770

¿Responde el puente?

PowerShell
Test-NetConnection 127.0.0.1 -Port 8765          # TcpTestSucceeded : True
Invoke-RestMethod http://127.0.0.1:8765/health -Headers @{ 'X-Bridge-Token' = 'TU_TOKEN' }

5Dos terminales: Conf principal y Conf secundaria

Para operar dos cuentas a la vez (p. ej. demo y fondeo) necesitas dos terminales MT5 y dos puentes, cada uno en su puerto.

  1. Instala MT5 una segunda vez en otra carpeta (o copia la carpeta del terminal) e inicia sesión con la otra cuenta.
  2. Guarda una vez la ruta del segundo terminal y su token en tu usuario.
  3. Arranca cada puente con -Perfil: cada uno abre su propia ventana, con su puerto y su token.
Una sola vez · variables de usuario
[Environment]::SetEnvironmentVariable('MT5_TERMINAL_PATH_SECUNDARIA', 'D:\MT5-Secundaria\terminal64.exe', 'User')
[Environment]::SetEnvironmentVariable('MT5_BRIDGE_TOKEN_SECUNDARIA', 'TOKEN_SECUNDARIO', 'User')
Arrancar los puentes
.\run-mt5-bridge.ps1 -Perfil principal    # 8765 · MT5_BRIDGE_TOKEN · MT5_TERMINAL_PATH (o el abierto)
.\run-mt5-bridge.ps1 -Perfil secundaria   # 8766 · MT5_BRIDGE_TOKEN_SECUNDARIA · MT5_TERMINAL_PATH_SECUNDARIA
PerfilURL del puenteTokenTerminal
Conf principalhttp://127.0.0.1:8765TOKEN_PRINCIPALMetaTrader 5
Conf secundariahttp://127.0.0.1:8766TOKEN_SECUNDARIOMT5-Secundaria

Luego el selector de Configuración decide a qué cuenta va cada operación confirmada.

6¿Hay que abrir puertos?

No, en el uso normal. La API, el puente y MT5 corren en el mismo Windows y se hablan por 127.0.0.1 (loopback). El firewall de Windows no bloquea ese tráfico y el router no interviene. MT5 solo hace conexiones salientes al broker, que ya funcionan si puedes iniciar sesión.
  • No configures “port forwarding” en el router ni expongas el puente a Internet: quien llegue a ese puerto podría abrir operaciones en tu cuenta.
  • Si Windows muestra el aviso “Permitir acceso a Python” al arrancar el puente, puedes cancelarlo: no afecta al tráfico local.
  • La app solo acepta URLs de puente localhost / 127.0.0.1 en Configuración, a propósito.
  • La lista “Permitir WebRequest para las URL” de MT5 (Herramientas → Opciones → Asesores Expertos) no hace falta: solo aplica a Expert Advisors MQL5, y este puente usa la librería Python.

Si de verdad el terminal está en otro PC

No está soportado por la app. La alternativa segura es un túnel (SSH o VPN tipo Tailscale) que haga aparecer el puente remoto como 127.0.0.1:puerto en tu máquina. Solo como referencia, una regla de firewall restringida a una IP sería:

PowerShell (Administrador) · solo referencia
New-NetFirewallRule -DisplayName "MT5 Bridge 8765" -Direction Inbound -Protocol TCP `
  -LocalPort 8765 -RemoteAddress 192.168.1.50 -Action Allow
# Quitarla:
Remove-NetFirewallRule -DisplayName "MT5 Bridge 8765"

Checklist final

  • MT5 abierto, sesión iniciada (demo) y Algo Trading en verde.
  • Token generado y guardado en MT5_BRIDGE_TOKEN.
  • Puente arrancado: “Escuchando en http://127.0.0.1:8765”.
  • Configuración: URL y token del perfil guardados, perfil correcto en uso.
  • “Probar conexión” muestra Conectado con la cuenta esperada.
  • Símbolos del broker revisados para BTC, US30 y XAUUSD.
  • Primera operación de prueba confirmada en demo antes de pensar en real.
