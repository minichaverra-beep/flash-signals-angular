Instalar Flash Signals en Android

Cómo correr la app (API Express + UI Angular) y el stack Cursor Trading (Python, ML, Neural) en un Motorola Edge 40 Neo con Android 15: se empaqueta todo en el PC, se copia por USB y se instala con un solo script en Termux. Todo corre en el teléfono, en http://localhost:3847.

  • Termux es la terminal Linux de Android. Dentro corre un Ubuntu ARM64 (proot, sin root) donde se instalan Node y Python.
  • Un solo proceso: la API sirve la interfaz compilada en el mismo puerto. No hace falta Angular CLI ni ng serve en el teléfono.
  • Las señales se ejecutan con Cursor Trading/scripts/analyze/analyze.sh, que acepta los mismos flags que los .ps1 (-ML, -Neural, -Bullish, -Entry…).
  • Las versiones de Python (scikit-learn, numpy, joblib…) se copian del PC para que los modelos entrenados carguen igual.
¿Necesita internet? Sí, la primera instalación descarga Ubuntu, Node y las librerías Python (gratis, ~2–3 GB). Después, los análisis usan internet solo para los datos de mercado (yfinance / Binance), igual que en el PC. No hay servidores de pago.

1Empaquetar en el PC

Detén la API si está corriendo (para que el historial .sqlite quede consistente) y ejecuta el empaquetador. Compila Angular, copia ambos repos sin .git ni node_modules (incluye models/, data/*.parquet y el modelo neural .pt) y fija las versiones Python.

PowerShell · carpeta flash-signals-angular
cd "D:\Danilo\Trading\flash-signals-angular"
.\android\pack-for-android.ps1

# Ya compilaste Angular y no cambiaste la UI:
.\android\pack-for-android.ps1 -SkipBuild

Genera dos archivos:

Salida esperada
Listo (94.3 MB):
  D:\Danilo\Trading\flash-signals-angular\android\out\flash-android.tar.gz
  D:\Danilo\Trading\flash-signals-angular\android\out\termux-install.sh

2Copiar al teléfono

  1. Conecta el Motorola por USB y en la notificación elige Transferencia de archivos.
  2. En el Explorador de Windows abre motorola edge 40 neo → Almacenamiento interno → Download.
  3. Copia flash-android.tar.gz y termux-install.sh ahí.
Alternativa sin cable Google Drive, Telegram “Mensajes guardados” o similar: lo importante es que ambos archivos terminen en Download/ con esos nombres exactos.

3Instalar Termux

  1. Descarga Termux desde F-Droid o desde GitHub Releases (archivo …arm64-v8a.apk).
  2. Si Android lo pide, permite Instalar apps desconocidas para el navegador o el gestor de archivos.
  3. Opcional: instala también Termux:Widget desde la misma fuente para tener un ícono de arranque.
No uses la versión de Play Store Está desactualizada y sus repositorios de paquetes fallan. Termux y sus complementos (Widget) deben venir de la misma fuente (todo F-Droid o todo GitHub), si no Android rechaza la combinación.

4Ejecutar el instalador

Abre Termux y ejecuta:

Termux
bash /sdcard/Download/termux-install.sh

Qué hace (20–40 min la primera vez, según Wi-Fi):

  1. Pide el permiso de almacenamiento (acepta el diálogo de Android).
  2. Instala proot-distro y un Ubuntu ARM64.
  3. Extrae el paquete en /opt/flash dentro de Ubuntu.
  4. Instala Python 3 + venv con las versiones del PC, torch (Neural), Node 22 y las dependencias npm del server.
  5. Verifica que los modelos models/*.joblib cargan.
  6. Crea ~/flash-start.sh y el atajo de widget Flash Signals.

Opciones

Termux · variantes
# Sin torch (ahorra ~600 MB; -Neural no estará disponible)
SKIP_NEURAL=1 bash /sdcard/Download/termux-install.sh

# Con OCR (onnxruntime + rapidocr, para extraer ops de capturas)
WITH_OCR=1 bash /sdcard/Download/termux-install.sh

# Reinstalar desde cero (borra historial y live/ del teléfono)
bash /sdcard/Download/termux-install.sh --fresh
Mantén la pantalla encendida durante la instalación Si Android suspende Termux a mitad de la descarga, vuelve a ejecutar el mismo comando: es seguro repetirlo.

5Arrancar y usar

Termux
~/flash-start.sh
  • Activa el wake lock de Termux y a los ~8 s abre Chrome en http://localhost:3847.
  • Con Termux:Widget: añade el widget a la pantalla de inicio y toca Flash Signals.
  • Para detener: vuelve a Termux y pulsa Ctrl+C (en el teclado extra de Termux: CTRL y luego c).
  • Consejo: en Chrome, menú ⋮ → Añadir a pantalla de inicio para abrir la UI como app.

6Ajustes de Android 15 (evitar que mate el servidor)

Android cierra procesos en segundo plano agresivamente. Haz esto una vez:

  1. Batería: Ajustes → Apps → Termux → Batería → Sin restricciones.
  2. Procesos secundarios: activa Opciones de desarrollador (Ajustes → Acerca del teléfono → toca 7 veces Número de compilación) y luego Sistema → Opciones de desarrollador → Desactivar restricciones de procesos secundarios.
  3. Deja la notificación de Termux visible (el wake lock la mantiene).

Alternativa por ADB (si no aparece la opción)

PowerShell en el PC · con depuración USB activa
adb shell "/system/bin/device_config set_sync_disabled_for_tests persistent"
adb shell "/system/bin/device_config put activity_manager max_phantom_processes 2147483647"
adb shell settings put global settings_enable_monitor_phantom_procs false
Señal típica de este problema Termux muestra [Process completed (signal 9)] tras unos minutos en segundo plano.

Actualizar tras cambios en el PC

  1. En el PC: .\android\pack-for-android.ps1 (con la API detenida).
  2. Copia de nuevo flash-android.tar.gz (y termux-install.sh) a Download/, reemplazando los anteriores.
  3. En Termux: bash /sdcard/Download/termux-install.sh.
Qué se conserva El historial del teléfono (flash-signals-angular/data: SQLite, capturas) y Cursor Trading/live. Se actualizan código, UI, modelos y .parquet. Reentrena en el PC y vuelve a empaquetar: en el teléfono es lento.

Limitaciones

FunciónEn AndroidMotivo / alternativa
Señales Context / Light / High / HistorySíVía analyze.sh
ML (.joblib)SíVersiones fijadas desde el PC
Neural (-Neural)Sí, si torch se instalóMás lento que en el PC; SKIP_NEURAL=1 lo omite
MACD-quant, historial, wikiSíSQLite local (better-sqlite3 o sql.js)
Envío a MetaTrader 5NoLa librería MetaTrader5 solo existe en Windows; opera MT5 desde el PC
Reentrenar modelosPosible, lentoEntrena en el PC y reempaqueta
Solo localhost La API escucha en 127.0.0.1. No la expongas a la red (BIND_HOST=0.0.0.0) salvo en una Wi-Fi de confianza: cualquiera en esa red podría usarla.

Checklist final

  • Paquete generado en el PC con la API detenida.
  • flash-android.tar.gz y termux-install.sh en Download/ del teléfono.
  • Termux (y Termux:Widget) instalados desde F-Droid o GitHub, misma fuente.
  • Instalador terminado con “Instalación completa” y modelos OK.
  • Termux con batería Sin restricciones y restricciones de procesos secundarios desactivadas.
  • ~/flash-start.sh abre http://localhost:3847 en Chrome.
  • /api/health muestra "signalRunner":"bash".
  • Primer análisis BTC Light completado desde la UI.
