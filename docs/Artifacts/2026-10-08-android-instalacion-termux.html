Instalar Flash Signals en Android con el APK

Cómo correr Flash Signals (API + UI) y el stack Cursor Trading (Python, ML, Neural) en un Motorola Edge 40 Neo con Android 15: compilas FlashSignals.apk en el PC, lo instalas y la app hace el resto con 4 botones. Todo corre en el teléfono, sin comandos salvo un pegado único en Termux.

Modelos del PC
  • El APK lleva dentro flash-android.tar.gz (código, UI compilada, modelos .joblib/.pt, .parquet) y el instalador.
  • La app copia ese paquete a Download/FlashSignals/, le pide a Termux que lo instale en un Ubuntu ARM64 (sin root) y luego arranca el servidor en segundo plano.
  • Cuando /api/health responde, la app muestra la interfaz dentro de sí misma.
  • Las versiones de Python (scikit-learn, numpy, joblib…) se copian del PC para que los modelos carguen igual.
¿Por qué hace falta Termux? Android no deja que una app normal ejecute Node, Python ni bash. Termux sí; la app Flash Signals solo le da órdenes. Lo instalas una vez y no necesitas usarlo. Docker no es opción: Android sin root bloquea lo que Docker necesita.
¿Necesita internet? Sí, la primera instalación descarga Ubuntu, Node y librerías Python (gratis, ~2–3 GB). Después, solo los datos de mercado (yfinance / Binance) usan internet, igual que en el PC.

1Compilar el APK en el PC

Detén la API si está corriendo (para que el historial .sqlite quede consistente) y ejecuta:

PowerShell · carpeta flash-signals-angular
cd "D:\Danilo\Trading\flash-signals-angular"
.\android\build-apk.ps1              # empaqueta + compila Angular + APK
.\android\build-apk.ps1 -SkipBuild   # sin recompilar Angular
.\android\build-apk.ps1 -SkipPack    # reutiliza el paquete ya generado
Salida esperada
BUILD SUCCESSFUL in 35s
Listo (94.7 MB): D:\Danilo\Trading\flash-signals-angular\android\out\FlashSignals.apk
Antivirus con inspección TLS (AVG) El script le indica a Gradle que use el almacén de certificados de Windows (-Djavax.net.ssl.trustStoreType=Windows-ROOT). Sin eso falla con PKIX path building failed.

2Instalar el APK en el teléfono

  1. Pasa android\out\FlashSignals.apk al teléfono (USB → Download, Drive o Telegram).
  2. Ábrelo desde Archivos y permite Instalar apps desconocidas para esa app cuando Android lo pida.
  3. Si Play Protect avisa de una app desconocida: Más detalles → Instalar de todas formas (está firmada con tu clave de depuración).

3Configurar con los 4 botones (solo la primera vez)

1 · Instalar Termux (F-Droid)

Abre F-Droid; también sirve GitHub Releases (…arm64-v8a.apk). Instálalo, ábrelo una vez (prepara su entorno) y vuelve a Flash Signals. El botón cambia a Termux instalado ✓.

No uses Termux de Play Store Está desactualizado y sus repositorios fallan.

2 · Permitir que Flash Signals use Termux

La app copia este comando y abre Termux. Mantén pulsado en la pantalla → Pegar → Enter:

Termux · una sola vez
mkdir -p ~/.termux && echo 'allow-external-apps = true' >> ~/.termux/termux.properties && termux-reload-settings

Es un candado de seguridad de Termux: sin él ninguna otra app puede pedirle que ejecute comandos.

3 · Instalar / actualizar Flash Signals

  1. Acepta el permiso «Ejecutar comandos en el entorno de Termux».
  2. La app copia el paquete a Download/FlashSignals/ (verás Copiando… MB).
  3. Se abre Termux con el progreso. Acepta el permiso de almacenamiento de Termux.
  4. Espera Instalación completa (20–40 min la primera vez: Ubuntu, Python, torch, Node, modelos verificados).
  5. Pulsa Enter para cerrar y vuelve a Flash Signals.
Mantén la pantalla encendida durante la instalación Si Android suspende Termux a mitad, vuelve a pulsar el botón 3: es seguro repetirlo.

4 · Iniciar y abrir

Arranca el servidor en segundo plano (verás Arrancando servidor… N s, unos 10–30 s) y muestra la interfaz dentro de la app. Termux deja una notificación mientras el servidor corre.

4Ajustes de Android 15 (evitar que mate el servidor)

  1. Batería: Ajustes → Apps → Termux → Batería → Sin restricciones.
  2. Procesos secundarios: activa Opciones de desarrollador (Ajustes → Acerca del teléfono → toca 7 veces Número de compilación) y luego Sistema → Opciones de desarrollador → Desactivar restricciones de procesos secundarios.

Alternativa por ADB (si no aparece la opción)

PowerShell en el PC · con depuración USB activa
adb shell "/system/bin/device_config set_sync_disabled_for_tests persistent"
adb shell "/system/bin/device_config put activity_manager max_phantom_processes 2147483647"
adb shell settings put global settings_enable_monitor_phantom_procs false

Uso diario

  • Abrir: toca el ícono Flash Signals. Si el servidor no corre, la app lo arranca sola y muestra la UI.
  • Volver a los botones: botón atrás del teléfono (cuando la UI no tiene más historial).
  • Detener: botón Detener servidor (libera batería y el wake lock de Termux).
  • En Chrome: con el servidor corriendo también puedes abrir http://localhost:3847.

Actualizar tras cambios en el PC

  1. En el PC: .\android\build-apk.ps1 (con la API detenida).
  2. Instala el APK nuevo encima del anterior (no lo desinstales).
  3. En la app: Detener servidor → 3 · Instalar / actualizar → 4 · Iniciar y abrir.
Qué se conserva El historial del teléfono (flash-signals-angular/data: SQLite, capturas) y Cursor Trading/live. Se actualizan código, UI, modelos y .parquet. Reentrena en el PC: en el teléfono es lento.
Compila siempre en el mismo PC El APK se firma con la clave de depuración de este PC; uno firmado en otro PC no se instala encima (habría que desinstalar y perder los permisos concedidos).
