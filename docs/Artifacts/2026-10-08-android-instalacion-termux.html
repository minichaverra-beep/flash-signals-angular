Instalar Flash Signals en Android con el APK

Cómo correr Flash Signals (API + UI) y el stack Cursor Trading (Python, ML, Neural) en un Motorola Edge 40 Neo con Android 15: compilas el APK, preparas el teléfono con un comando por ADB y en la app solo pulsas Instalar e Iniciar.

Modelos del PC
  • El APK lleva dentro el paquete (código, UI compilada, modelos .joblib/.pt, .parquet) y el instalador.
  • La app lo copia a Download/FlashSignals/, le pide a Termux que lo instale en un Ubuntu ARM64 (sin root) y arranca el servidor en segundo plano.
  • Las versiones de Python (scikit-learn, numpy, joblib…) se copian del PC para que los modelos carguen igual.
Termux de Google Play NO sirve Esa versión (googleplay.*) no trae RunCommandService: la app no puede darle órdenes y el botón Instalar se queda en «Copiando…». Usa Termux de GitHub (o F-Droid). El script de ADB lo detecta y lo reemplaza solo.
¿Necesita internet? Sí, la primera instalación descarga Ubuntu, Node y librerías Python (gratis, ~2–3 GB). Después, solo los datos de mercado (yfinance / Binance) usan internet, igual que en el PC. Docker no es opción: Android sin root lo bloquea.

1Compilar el APK en el PC

Detén la API si está corriendo (para que el historial .sqlite quede consistente):

PowerShell · carpeta flash-signals-angular
cd "D:\Danilo\Trading\flash-signals-angular"
.\android\build-apk.ps1              # empaqueta + compila Angular + APK
.\android\build-apk.ps1 -SkipBuild   # sin recompilar Angular
Salida esperada
BUILD SUCCESSFUL in 35s
Listo (94.7 MB): D:\Danilo\Trading\flash-signals-angular\android\out\FlashSignals.apk
Antivirus con inspección TLS (AVG) El script hace que Gradle use el almacén de certificados de Windows; sin eso falla con PKIX path building failed.

2Preparar el teléfono (un comando por ADB)

setup-phone-adb.ps1 instala Termux de GitHub (reemplaza el de Play si existe), instala FlashSignals.apk, concede los permisos, activa allow-external-apps y aplica los ajustes de batería y procesos de Android 15. Sustituye los botones 1 y 2 de la app y todos los ajustes manuales.

a) Activar depuración inalámbrica (una vez)

  1. Ajustes → Acerca del teléfono → toca 7 veces Número de compilación.
  2. Ajustes → Sistema → Opciones de desarrollador → activa Depuración inalámbrica.
  3. Entra en Depuración inalámbrica: anota la IP y puerto de la pantalla principal (conexión).
  4. Toca Vincular dispositivo con código: anota el código y la IP:puerto de esa ventana (vinculación). Caduca en ~2 min.

b) Ejecutar el script

PowerShell · carpeta flash-signals-angular
# Primera vez: vincular + conectar + preparar
.\android\setup-phone-adb.ps1 -PairAddress 192.168.78.166:35529 -PairCode 123456 -Device 192.168.78.166:34333

# Ya vinculado (los puertos cambian al reactivar la depuración inalámbrica)
.\android\setup-phone-adb.ps1 -Device 192.168.78.166:34333
Salida esperada
   Teléfono: motorola edge 40 neo · Android 15
   [OK] Termux con RunCommandService
   [OK] allow-external-apps activo
   [OK] Flash Signals: RUN_COMMAND
   [OK] Límite de procesos quitado
Teléfono listo. En la app pulsa "3 · Instalar / actualizar" y luego "4 · Iniciar y abrir".
No lo ejecutes durante una instalación Si tiene que activar allow-external-apps reinicia Termux, lo que cortaría el botón 3 en curso. Prepara primero y luego instala. Si adb pair falla con protocol fault, el script reintenta; si sigue, genera un código nuevo.

Alternativa sin PC (manual)

  1. Instala FlashSignals.apk y Termux …arm64-v8a.apk de GitHub con el Instalador de paquetes (desinstala antes el Termux de Play).
  2. Abre Termux una vez. En la app, botón 2: pega el comando en Termux → Enter.
  3. Ajustes → Apps → Termux → Batería → Sin restricciones; Opciones de desarrollador → Desactivar restricciones de procesos secundarios.

3Instalar Flash Signals (botón 3)

  1. En la app pulsa 3 · Instalar / actualizar Flash Signals.
  2. La app copia el paquete a Download/FlashSignals/ (verás Copiando… MB) y abre Termux.
  3. Espera Instalación completa: 20–40 min la primera vez (Ubuntu, Python, torch, Node, verificación de modelos).
  4. Pulsa Enter para cerrar y vuelve a Flash Signals.
Pantalla encendida y Wi-Fi durante la instalación Si se corta (Termux cerrado, sin red), pulsa el 3 otra vez: es seguro y retoma lo que falte.

4Iniciar y abrir (botón 4)

Arranca el servidor en segundo plano (Arrancando servidor… N s, unos 10–30 s) y muestra la interfaz dentro de la app. Termux deja una notificación mientras el servidor corre.

Uso diario

  • Abrir: toca el ícono Flash Signals. Si el servidor no corre, la app lo arranca sola y muestra la UI.
  • Volver a los botones: botón atrás (cuando la UI no tiene más historial).
  • Detener: botón Detener servidor (libera batería y el wake lock).
  • En Chrome: con el servidor corriendo también funciona http://localhost:3847.

Actualizar tras cambios en el PC

  1. En el PC: .\android\build-apk.ps1 (con la API detenida).
  2. Instala el APK nuevo encima: .\android\setup-phone-adb.ps1 -Device IP:PUERTO (lo instala y revisa todo) o con el Instalador de paquetes.
  3. En la app: Detener servidor → 3 → 4.
Qué se conserva El historial del teléfono (flash-signals-angular/data) y Cursor Trading/live. Se actualizan código, UI, modelos y .parquet. Reentrena en el PC: en el teléfono es lento.
Compila siempre en el mismo PC El APK va firmado con la clave de depuración de este PC; uno firmado en otro PC no se instala encima.
