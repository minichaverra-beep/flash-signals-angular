Cómo usar Flash Signals

  1. Elegir mercado y tier. BTC o US30, y el nivel: Context (estructura), Light (rápido), High (entrada del día) o History (P&L, no es señal).
  2. Ejecutar señal. Pulsa «Ejecutar señal» y espera a que el pipeline termine. También puedes «Recargar último reporte».
  3. Trader vs Inversor. Trader muestra KPIs técnicos, scores y checklists. Inversor resume la decisión en lenguaje simple.
  4. Historial local. Cada corrida se guarda en la caja SQLite embebida. Ábrela desde el enlace Historial del header.
  5. No inventa señales. El resultado sale del pipeline real (datos + reglas + ML). Si no hay setup válido, verás NO_OPERAR / Esperar.
  6. Abrir gráfico PNG. En el reporte, la card «Gráfico» abre /api/signals/chart en una pestaña nueva.
  7. Si falla la API o la web. Reinicia run-api / run-local-web (o npm run api + el front) y vuelve a cargar.
